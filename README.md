# Better Structures (Bedrock)

A personal Minecraft Bedrock add-on for family worlds. It converts buildings from Java structure mods to Bedrock and places them with a Structure Wand, including whole villages assembled by script.

Download `BetterStructures.mcaddon` from the [latest release](../../releases/latest) and open it with Minecraft, then activate the pack in a world.
